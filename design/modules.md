# Module map

Moved from CLAUDE.md. Codex is in design/codex.md.

- `Sources/` is the app: `Store` (the one `@Observable` owner of tabs, groups and live status), `Sidebar`, `ContentView`, `Launcher` (⌘N / ⇧⌘F / ⌘K overlay), `AppAction`, `GhosttyConfig` (loads the user's Ghostty config), `FileWatcher` (FSEvents), `ProcessAncestry`, `Harbor` (the ambient boats view), `ReviewView` (Review's panel, diff column and `ReviewModel`), `ReviewLanguage` (Review's language servers and diagnostics), `LanguageServerEditor` (the server entry sheet in Settings), `ReviewDiffPane` + `ReviewTextView` (its TextKit 2 diff), `ReviewInlineComment` (the diff's comment box and cards), `ReviewMinimap` (minimap and overview ruler), `ReviewStyle` (Review's colour schemes, font and line height), `ReviewHighlighter` (tree-sitter spans), `ReviewPathBar`, `SessionHoverCard`, `SidebarFilter`, `WorkingDots`, `AppUpdater` + `RestartBanner`, `VisibleDropTerminalView`, `Snapshot` (DEBUG capture hook), `RemoteServer` (the remote control WebSocket).
- `Shared/` is compiled into both apps: `CodeHighlighter` (tree-sitter spans for Review, the Conversation view and Berth Remote; text plus language, extension or fence name in, spans out).
- `BerthRemote/` is the iOS app (its own scheme), sharing only `BerthCore/RemoteProtocol.swift` with the Mac app. Releases: `package-ios.sh` and `docs/RELEASING.md`.
- `Packages/BerthCore/` is pure logic and its tests: transcript head/tail parsing, live `sessions/<pid>.json` decoding, grouping (`SessionGrouping`: modes, custom group rules, recent buckets), `SessionArchive`, `SessionPins`, `IdleTabs` (which Claude tabs to unload), `RepositoryRoot`, `FuzzyMatch`, `ClaudeLaunch` (the claude command line), `LiveSession`, `NeedsYou` (which sessions just entered `waiting`), `LanguageServer` + `LanguageServers` (the LSP client; `LanguageServerEntry`, matching, root markers and command resolution), `TranscriptSearch` (the search index), `CommandPalette` (the ⌘K palette's ranking), `UsageStats` (the Stats window's aggregation), `ReviewGit` (Review mode's git layer), `ReviewDiff` (line alignment and word changes), `ReviewCarets` (multi-cursor caret normalizing and occurrence matching), `TaskFormation` (stored tasks + per-session signals in, tasks + branch suggestions out; `IssueRef`, `StoredTask`, `TaskState`, `SessionTask`), `ReviewComment` (comments and the prompt they are sent as), `TranscriptTail` (the remote's transcript reader), `TranscriptActivity` (the remote's running tasks and context size). Fixtures are invented, never real transcripts.
- Terminal engine: `Lakr233/libghostty-spm` (MIT), product `GhosttyTerminal`, pinned `exactVersion` in `project.yml`.
