# CLAUDE.md changes for review-panel-flows

- Panel tabs: `ReviewPanelTab` is `changes`, `files` only, a full-width segmented `Picker` with the panel's Refresh capsule beside it on both tabs (32 pt row, hairline below). A stored `comments` or `preview` is moved once (while `persistsTabs` is on, or per launch in snapshots): `preview` opens the diff column's Preview, `comments` expands the comment list; the stored value becomes `changes`. `-snapshotReviewPanelTab changes|files|comments|preview` (the last two via that move). Refresh is at about 401,55 at the default width (was 248,67).
- Comments: a bar pinned at the bottom of the panel on every tab (a sibling below the list in the panel's VStack, so rows never sit under it), hidden at 0 comments: a Comments disclosure (`ReviewModel.showsCommentList`, in memory, opened by a new Preview pick) and a prominent accent Send N Comments. The list scrolls past 220 pt; a comment row opens its document on a single click or the Open button (Preview comments open Preview), × deletes. The snapshot edit-comment hook sets `showsCommentList` and clicks the row at 100,90 (bottom-left origin).
- Preview moved out of the panel into the diff column: `ReviewModel.isPreviewOpen` / `isPreviewSelected` (in memory), a Preview tab after the file tabs (globe, ×) and a labelled Preview capsule in the strip while it is closed. View ▸ Open Preview and the palette (`AppAction.openPreview`, no shortcut, available while the panel shows and Preview isn't selected). Assigning `selectedTabID` deselects it. ⌘W / `Store.closeDiff()` closes only Preview while it is selected, leaving file tabs. The `WKWebView` lives in `ReviewModel.preview`, so switching tabs keeps the page and its loopback rules. The toolbar's Pick button is labelled Pick with a tooltip. `-snapshotPreview <address>` opens it first.
- `IconTabBar` is only the session sidebar's status filter now: 24 pt buttons with a 10% rounded fill, the selected one also showing its title.
