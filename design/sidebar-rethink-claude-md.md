# CLAUDE.md changes for sidebar-rethink

Apply to the Berth CLAUDE.md (a symlink outside the repo).

- Grouping: sidebar order is now Needs Attention, Terminals, Active (Recent modes only), Pinned, the groups, Archived. Needs Attention (`SidebarLayout.attentionIDs`, id `Sidebar.attentionID`, `Store.attentionSessions`) holds sessions in no task whose live status is waiting, or whose open or draft PR has failing checks, newest first, waiting before failing. Pinned (not live) sessions qualify too and leave Pinned; sessions leave Active and the groups, so a row never appears twice. Unread never qualifies (it stays in the rows' own sections), so selecting a row never moves it. Rows use the compact density (title, PR tag, time; no line 2) and the header is tinted `theme.needsYou`. It counts in Collapse/Expand All and leads `Store.sidebarOrderedTabs` (⌘1-9, ⌃⇥), so the keyboard order matches the sidebar.
- Active shows at least 5 sessions and every one up to the last that isn't idle or is the selected session (`SidebarLayout.Group.visibleLimit`), the rest behind Show N More (`expandedGroups`, id `recent:active`). A group left empty by Needs Attention is dropped.
- The status icon row is gone. The filter field sits at the top in the 32 pt strip (hairline below); its leading menu (with a chevron) picks the status filter (All, Working, Needs You, Unread, Flagged, with counts) and, when set, shows the status and its count in accent colour in the field. `-snapshotSidebarStatus` still sets the status; `-snapshotSidebarFilter` also prints `attention`.
- `IconTabBar` is removed: the sidebar's status filter is the filter field's menu, and Review's panel tabs are review-panel-flows' segmented Picker.
- Terminal rows use the compact density (one line, folder only if it fits) and show their folder as a tooltip.
- Rows: the context ring shows from 80% (was 60%) and a passed checks mark is hidden on the row's PR tag (failed and running stay; the hover card and Review show all).
- Snapshot fixtures: `-snapshotChecks "passed|passed||failed"` fails the draft #12 session's checks so it enters Needs Attention. 20+ idle live sessions: a `CFFIXED_USER_HOME` with 28 invented transcripts and `sessions/<n>.json` files (pid 1; one busy, one waiting, one shell, the rest idle), run with `-groupingMode recent -sidebarPosition left -showsReviewPanel NO -languageServersEnabled NO` and `-snapshotGhosttyTheme "Atom One Dark"`.
